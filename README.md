# Hafsa Traders Android App

Hafsa Traders customer and admin Android application.

## Build

The repository includes a CodeMagic configuration with Debug and Release APK/AAB workflows. CodeMagic downloads Gradle 9.3.1 explicitly so the build does not depend on the machine's preinstalled Gradle version.

**Application ID:** `com.hafsatraders.app`

For a signed Play Store release, configure your signing key securely in CodeMagic. Never commit a keystore or passwords to GitHub.
